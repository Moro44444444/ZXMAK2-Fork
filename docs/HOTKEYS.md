# Горячие клавиши ZXMAK2 Fork

Актуально для стабильной локальной v54 (WinForms), 26 сентября 2026 года.
Это рабочий справочник для будущей инструкции. Сочетания сверены с кодом;
наличие обработчика не означает завершённую ручную проверку нажатий.

## Главное окно эмулятора

Клавиши действуют, когда фокус находится в главном окне. В диалогах,
отладчике и внутри программ ZX Evolution управление может отличаться.

| Клавиши | Действие | Примечание |
| --- | --- | --- |
| Alt+Enter | Full Screen: полный экран / окно | С v54 Enter не передаётся машине; учитывается и Enter цифрового блока. |
| Alt+P | Machine Settings | С v53 P не передаётся машине. |
| Ctrl+S | Maximum Speed: включить / выключить максимальную скорость | С v54 S не передаётся машине. Это **не сохранение файла**. |
| F11 | No Border: показать / скрыть бордюр | Пункт View > Scale Mode > No Border. |
| Pause | Пауза / продолжить выполнение машины | Не путать с остановкой ленты. |
| F12 | Warm Reset | Обычный сброс машины. |
| Ctrl+F12 | CMOS Reset | С подтверждением; нужна машина с поддержкой сброса CMOS. |
| Ctrl+Alt+F12 | Factory Reset | С подтверждением; возвращает исходное состояние эмулятора и перезапускает его. |
| Ctrl+Alt+F1 | Quick Load | Загрузка быстрого образа из boot.zip; доступна при активном TR-DOS и наличии файла. |
| Ctrl+Alt+F8 | Play / Stop Tape | Переключает воспроизведение ленты при наличии Tape Player. |
| Ctrl+Alt | Освободить захваченную мышь | Обработка выполняется при событии нажатия клавиши с обоими модификаторами. |

Alt+P и Alt+Enter учитывают правый Alt (AltGr), который Windows может
представлять как Alt вместе с синтетическим Ctrl. Для Ctrl+S учитываются
оба Ctrl; Ctrl+Shift+S не назначен команде Maximum Speed.

Изоляция гостевой клавиатуры явно добавлена только для Alt+P, Alt+Enter
и Ctrl+S. Для остальных команд в этом справочнике она не заявляется.

## Клавиши AVR ZX Evolution BaseConf

Это управление эмулируемым оборудованием, а не команды интерфейса Windows.

| Клавиша | Действие |
| --- | --- |
| Scroll Lock | Следующий видеорежим AVR: варианты TV/VGA и таймингов; соответствует EVO Display Mode в меню. |
| Num Lock | Переключить аппаратный вариант выхода beeper/tape-out (бит D3/D4 порта FE). |

## Отладчики: отдельный контекст

В основном/расширенном стандартном отладчике: F5 — остановка,
F7 — шаг с заходом, F8 — шаг с обходом вызова, F9 — продолжить.
В старом стандартном FormCPU также есть F3 — сброс остановленной машины.

В отладчике Adlers:

| Клавиши | Действие |
| --- | --- |
| F3 | Сброс остановленной машины. |
| F5 | Остановить выполнение. |
| F7 | Шаг с заходом (на остановленной машине). |
| F8 | Шаг с обходом вызова (на остановленной машине). |
| F10 | Продолжить выполнение. |
| F12 | Переключить панель Stack / Breakpoints; это не Warm Reset. |
| Ctrl+F | Поиск байтов в памяти. |
| Ctrl+N | Найти следующее совпадение. |
| Ctrl+G | Перейти к адресу в дизассемблере. |
| Ctrl+D | Перейти к адресу в дампе памяти. |
| Ctrl+1 | Вставить комментарий. |
| Ctrl+2 | Вставить примечание. |
| Escape | Убрать сообщение командной строки либо скрыть окно отладчика. |
| Insert | В командной строке переключить вставку / перезапись. |

Стрелки и Page Up / Page Down служат навигации по панелям отладчика;
Enter открывает редактирование в поддерживающих его панелях.
В отдельном окне ассемблера Adlers:

| Клавиши | Действие |
| --- | --- |
| F5 | Сборка исходного текста. |
| Ctrl+O | Открыть исходный файл. |
| Ctrl+S | Сохранить исходный файл; здесь это не Maximum Speed. |
| Delete | В дереве исходников удалить выбранный исходник из списка. |
| Escape | В окне настройки цветов ассемблера скрыть это окно. |

## Отменённые и неназначенные сочетания

- Ctrl+B, Alt+F9 и Ctrl+Alt+F11 не являются текущей привязкой No Border:
  действующая клавиша — F11.
- Alt+Ctrl+Insert больше не назначен Warm Reset; используется F12.
- Maximum Speed: старая подпись Ctrl+Scroll и старый обработчик Alt+Scroll
  заменены на Ctrl+S. Сам Scroll Lock остаётся клавишей AVR-видеорежимов.
- Ctrl+P не открывает Machine Settings; обычные P, S и Enter доступны машине.
- Для Open, Save, NMI, Eject Tape и извлечения дисков отдельных сочетаний
  в текущем главном окне не назначено. Не придумывать их в инструкции.
