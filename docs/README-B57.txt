ZXMAK2 Fork — ZX Evolution BaseConf — v57 Joystick Test
26.09.2026

Запуск: ZXMAK2.exe. Это отдельная локальная тестовая сборка на базе v56.
Предыдущие сборки не изменены. На GitHub v57 не опубликована.

Machine Settings (Alt+P) -> JOYSTICK KEMPSTON:
- PC controller: устройства Windows с пометкой (DInput) / (XInput).
- Refresh controllers: перечитать устройства без перезапуска эмулятора.
- Directions Auto: крестовина/POV и основной стик одновременно.
  Также есть D-pad only, Stick only, Custom mapping, мёртвая зона.
- Назначить действие: щёлкнуть по нему, затем нажать кнопку или
  сдвинуть ось/крестовину. Esc отменяет, правый щелчок очищает.
- Fire настраивается; автоогонь Off / While Fire is held / Toggle button.
  Скорость 1–25 импульсов в секунду, по умолчанию 10.
- Input показывает текущий ввод. Apply сохраняет выбранное устройство
  и его назначения в профиле машины; у каждого устройства свои настройки.

Отключённое устройство не заменяется автоматически другим.
После переключения режима DInput/XInput: Refresh controllers, выбрать
нужную запись, Apply. Имя XInput уточняется по Windows, если сопоставление
однозначное; иначе Controller N (XInput). XInput-профиль относится к слоту
Windows, поэтому при нескольких геймпадах стоит проверить Input.
DInput: 8 осей, 4 POV, первые 32 кнопки; XInput: стики, крестовина,
основные кнопки и триггеры. HOTAS поддерживается через DInput.

Toggle-автоогонь останавливается при потере фокуса, отключении,
Refresh и сбросе. Для включения после этого кнопку отпустить и нажать
снова. Его активное состояние между запусками не сохраняется.
Звук, сеть, ULAplus, слоты карт, носители, иконки и глобальные
горячие клавиши сохранены. Файлы прошивок и нативные аудио DLL не менялись.

Подробности: JOYSTICKS.md. Горячие клавиши: HOTKEYS.md.
Физические контроллеры во время сборки не были подключены; требуется
ручная проверка вашего геймпада/HOTAS в обоих доступных режимах.
