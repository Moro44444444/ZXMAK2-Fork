# Historical build reports

This directory contains detailed reports for completed ZX-Evo BaseConf stages
that are no longer the current build. They are retained for reproducibility,
artifact hashes and investigation history.

- `results/` — detailed reports for B31 and B33–B40.
- `releases/` — README and metadata files from earlier Alpha/Beta packages.
- The remaining files in this directory contain the long-form project journal,
  changelog and conformance audits.

The canonical project history is `docs/history/PROJECT_JOURNAL.md`; the short
public-facing chronology is `docs/history/FORK_CHANGELOG.md`; the conformance
audits are kept alongside them.
