# Historical build reports

This directory contains detailed reports for completed ZX-Evo BaseConf stages
that are no longer the current build. They are retained for reproducibility,
artifact hashes and investigation history.

- `results/` — detailed reports for B31 and B33–B35.
- The current detailed report remains at the repository root as
  `B36_RESULT.md` until it is superseded by the next completed stage.

The canonical project history is `PROJECT_JOURNAL.md`; the short public-facing
chronology is `FORK_CHANGELOG.md`; the active conformance plan is
`BASECONF_AUDIT_B32.md`.
