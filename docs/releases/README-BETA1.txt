ZXMAK2 Fork — ZX Evolution BaseConf Beta 1

This portable build is based on the accepted B50 configuration. It includes
the current BaseConf device set, ZXBUS expansion boards, storage controls,
sound support and ZXNetUSB Rev.C Ethernet. The source code is tagged
v0.8-beta1 in the GitHub repository.

Highlights:
- TurboSound FM Pro, ZX-MultiSound, NeoGS and ZXM-MoonSound in either ZXBUS
  slot, with documented port and conflict handling;
- FDD, IDE/HDD, Z-controller SD, NeoGS SD, tape and CD-ROM controls with
  toolbar status indicators;
- W5300-based ZXNetUSB Rev.C TCP, UDP, DHCP and DNS through Windows networking;
- Warm Reset (F12), CMOS Reset (Ctrl+F12) and Factory Reset (Ctrl+Alt+F12).

The ZIP contains one root folder and excludes user-specific machine state,
mounted media, logs and PDB files. The Yamaha YRW801-M instrument ROM is not
redistributed; MoonSound PCM/wavetable playback requires a legally obtained
copy placed beside `ZXMAK2.exe`. Extract the ZIP and run `ZXMAK2.exe`.

ZXMAK2 Fork — ZX Evolution BaseConf Beta 1

Эта portable-сборка основана на принятой конфигурации B50. В неё входят
актуальный набор устройств BaseConf, платы расширения ZXBUS, управление
носителями, звуковая подсистема и сетевая плата ZXNetUSB Rev.C. Исходный код
помечен тегом v0.8-beta1 в GitHub-репозитории.

Главное:
- TurboSound FM Pro, ZX-MultiSound, NeoGS и ZXM-MoonSound в любом слоте ZXBUS
  с документированными портами и защитой от конфликтов;
- FDD, IDE/HDD, SD-карты Z-controller и NeoGS, лента и CD-ROM с индикаторами
  состояния на панели инструментов;
- TCP, UDP, DHCP и DNS ZXNetUSB Rev.C на базе W5300 через сеть Windows;
- Warm Reset (F12), CMOS Reset (Ctrl+F12) и Factory Reset (Ctrl+Alt+F12).

В ZIP одна корневая папка; пользовательские состояния машины, смонтированные
носители, логи и PDB-файлы исключены. Инструментальный ROM Yamaha YRW801-M не
распространяется: для PCM/wavetable-части MoonSound нужно поместить рядом с
`ZXMAK2.exe` собственную законно полученную копию. Распакуйте архив и запустите
`ZXMAK2.exe`.
