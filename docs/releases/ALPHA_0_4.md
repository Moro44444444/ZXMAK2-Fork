# ZX-Evo BaseConf Alpha 0.4 — B38

Portable prerelease based on the user-tested B38 baseline.

- Documented BaseConf eight-bit Kempston joystick (`#1F`), with VG93 ownership
  retained in Shadow/DOS.
- Tape input on `xxFE/xxF6` and the AVR-controlled beeper/tape-out mux.
- Previously accepted border/multicolor, media swap, IDE browsing, Rage,
  NedoOS, Bad Apple and audio paths are retained.

The ZIP has one root folder and excludes personal state, media images, logs,
PDB files and development probes. Extract it and run `ZXMAK2.exe`.

## Русская версия

Портативный prerelease на базе проверенной пользователем B38.

- Документированный восьмибитный Kempston BaseConf (`#1F`) с сохранением
  приоритета VG93 в Shadow/DOS.
- Tape-in на `xxFE/xxF6` и AVR-переключатель beeper/tape-out.
- Сохранены ранее принятые border/multicolor, смена носителей, IDE browsing,
  Rage, NedoOS, Bad Apple и звук.

ZIP содержит одну корневую папку и не включает пользовательские состояния,
образы носителей, логи, PDB и тестовые утилиты. Распакуйте архив и запустите
`ZXMAK2.exe`.
