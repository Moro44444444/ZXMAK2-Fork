ZXMAK2-Fork — v58 Joystick Interfaces Test — 2026-09-26

Открыть Machine Settings (Alt+P), выбрать Joystick.
Если устройства нет: Add -> Joystick -> JOYSTICK KEMPSTON.
Emulates: Kempston / Sinclair Joy 1 (6-0) / Sinclair Joy 2 (1-5) /
Cursor (AGF / Protek) / Fuller.
PC controller: выбрать устройство с именем Windows (DInput) или (XInput).
В игре выбрать соответствующий интерфейс. Нажать Apply.

Directions Auto: D-pad + stick — обычный удобный режим.
Custom mapping — отдельное назначение четырёх направлений.
Fire назначается кнопкой; Esc отменяет ожидание назначения.
Auto-fire: Off / While Fire is held / Toggle button; 1-25 выстрелов/с.
Refresh controllers — обновить список после подключения либо смены режима
геймпада; перезапуск эмулятора не нужен.
Выбор интерфейса, контроллера, назначения и автоогонь сохраняются с машиной.
Один виртуальный джойстик на машину. Варианты Sinclair обозначают раскладки.
Подробная инструкция и ограничения: JOYSTICKS.md, сочетания: HOTKEYS.md.

Загрузчик показывает:
BaseConf: BaseConf Emu (ZXMAK2-Fork)
AVR Boot: Boot Emu (ZXMAK2-Fork)
Адрес www.nedopc.com сохранён. Косметически изменена только страница меню
официальной ROM v0.61.01 FE. Остальные 31 страницы ROM и аппаратный формат
версий AVR не менялись. Исходный официальный ROM остался в прежних сборках
и ROMS.PAK; fork-образ размещён в roms/EVO/zxevo.rom.
Этот вариант ROM предназначен для эмулятора, не для прошивки настоящей EVO.

Это отдельная локальная тестовая сборка, без публикации GitHub.
Прежние версии не заменены. Проверены автотесты и реальный запуск EXE;
физический геймпад/HOTAS и конкретные игры требует проверить пользователь.
