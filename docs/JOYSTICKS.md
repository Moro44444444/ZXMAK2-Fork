# Джойстики и геймпады — WinForms v59

Открыть **Machine Settings (Alt+P) → Joystick**.
Изменения вступают в силу после **Apply** и сохраняются вместе с машиной.
Если устройства ещё нет: **Add → Joystick → JOYSTICK KEMPSTON**.
Оно доступно для всех машин; в правой панели `Emulates` выбирается интерфейс.

## Быстрый запуск

1. Подключить геймпад или HOTAS и выбрать его в `PC controller`.
   Имя берётся из Windows; справа добавляется `(DInput)` или `(XInput)`.
2. Оставить `Directions: Auto: D-pad + stick`: крестовина и основной
   стик работают одновременно, включая диагонали.
3. Для обычного Kempston по умолчанию любая кнопка — Fire.
   Чтобы выбрать одну, нажать строку **Fire**, затем нужную кнопку.
4. В `Emulates` выбрать Kempston, Sinclair Joy 1 (6–0), Sinclair Joy 2 (1–5),
   Cursor (AGF / Protek) или Fuller. Нажать **Apply** и выбрать тот же тип
   управления в игре. Названия Sinclair дополнены клавишами, поскольку
   некоторые программы по-разному нумеруют два порта.

## Эмулируемые интерфейсы

| Интерфейс | Left / Right / Down / Up / Fire |
| --- | --- |
| Kempston | Порт #1F, активные единицы; сохранены прежние маска и 5/8 бит |
| Sinclair Joy 1 | 6 / 7 / 8 / 9 / 0 |
| Sinclair Joy 2 | 1 / 2 / 3 / 4 / 5 |
| Cursor (AGF / Protek) | 5 / 8 / 6 / 7 / 0 |
| Fuller | #7F, активные нули: биты 2 / 3 / 1 / 0 / 7 |
| Kempston Extended (8-bit) | Прежний порт и маска Kempston; Fire 2/3/4 на битах 5/6/7 |

Sinclair и Cursor замыкают контакты клавиатурной матрицы одновременно
с обычной клавиатурой, не генерируют нажатия в Windows и не занимают порт
Kempston. Изменение `Emulates` не удаляет назначения PC-контроллера.
Один виртуальный джойстик на машину; два варианта Sinclair — выбор
раскладки, а не одновременное подключение двух игроков.

Подключение нового устройства либо переключение DInput/XInput не требует
перезапуска: нажать **Refresh controllers**, выбрать нужную запись и Apply.
При открытии настроек список также перечитывается. Фоновый непрерывный
поиск устройств не запускается: ручное обновление не мешает машине.

## Направления и кнопки

- `Auto`: D-pad/POV + основные оси X/Y. Противоположные направления
  взаимно гасятся. Мёртвая зона применяется только к аналоговым осям.
- `D-pad only` / `Stick only`: использовать только выбранный источник.
- `Custom mapping`: отдельные назначения Up, Down, Left, Right, Fire.
  Строки ручного назначения направлений видны только в этом режиме.
  Нажать действие, затем кнопку или направление крестовины/оси.
  При назначении направления включается Custom mapping.
- **Esc** отменяет ожидание назначения, не закрывая настройки.
  Ожидание заканчивается через 10 секунд или при потере фокуса/устройства.
- Правый щелчок по назначению: очистить его; у Fire также есть `Any button`.
- `Input` показывает полученные направления и Fire до применения настроек.
  Это проверка физического ввода, а не индикатор текущей очереди автоогня.
- `Restore mapping defaults` сбрасывает назначения выбранного устройства,
  но не меняет его, аппаратные порты или другие профили контроллеров.

Для HOTAS можно назначать разные оси, кнопки и POV. Поддерживаются восемь
осей, четыре POV и первые 32 кнопки DInput. XInput: оба стика, крестовина,
основные кнопки и оба триггера. Назначение сильно отклонённой оси требует
движения через нейтраль: это защищает от включённого направления в покое.

В 8-битном Kempston BaseConf сохранены дополнительные кнопки: физические
кнопки 2/3/4 дают биты 5/6/7. Основной Fire на бите 4 настраивается отдельно.
Выделенная кнопка переключения автоогня исключается из `Any button`
и дополнительных битов, чтобы сама по себе не становиться обычным Fire.

## Автоогонь

- `Off`: обычное нажатие Fire.
- `While Fire is held`: стрелять импульсами, пока удерживается Fire.
- `Toggle button`: назначить отдельную кнопку в **Auto-fire toggle**;
  одно нажатие запускает импульсы, следующее останавливает.
- `Shots / second`: 1–25, по умолчанию 10. Удобные значения: 6, 10, 15.

Импульсы рассчитаны по времени эмулируемой машины, а не по таймеру Windows.
Пауза замораживает фазу; режимы частоты CPU сами по себе её не ускоряют.
Maximum Speed ускоряет саму машину, поэтому импульсы тоже идут быстрее
относительно реального времени. Потеря фокуса, отключение контроллера,
обновление списка и сброс машины прекращают включённый Toggle-автоогонь.
Для повторного включения надо отпустить и снова нажать его кнопку.
Сохраняются режим и частота, но не состояние «сейчас стреляет».

## Сохранение и определение устройства

Назначения хранятся в XML-профиле машины отдельно для каждой записи PC
controller. Отключённое устройство остаётся выбранным с пометкой
`(disconnected)`: None или другой контроллер вместо него не выбираются.
Factory Reset (Ctrl+Alt+F12) сохраняет прежнюю логику возврата всей машины
к исходной конфигурации. Переназначения не меняют горячие клавиши эмулятора.

Имена одинаковых DInput-интерфейсов различаются суффиксами `[2]`, `[3]`.
Удаляются только точные дубли GUID; одинаковое название само по себе не
означает одно устройство. Возможны отдельные DInput/XInput-представления
одного геймпада — выбирается одно из них, ввод не объединяется автоматически.

**Ограничение XInput:** Windows API сообщает слот 1–4, а не постоянный
серийный идентификатор. При единственном активном XInput-контроллере имя
уточняется по PnP/VID/PID Windows. При неоднозначности используется
`Controller N (XInput)`, без придуманного имени. Если подключено несколько
XInput-геймпадов и Windows переставила их между слотами, проверить выбор
в `Input`; профиль XInput привязан к слоту. Доступный протокол определяется
драйвером/режимом устройства, эмулятор не переключает режим самого геймпада.

Расширение DInput до 128 кнопок не добавлено.
Keyboard Numpad сохранён: 8/2/4/6 — направления,
0 или 5 — Fire.

## Игровые профили и клавиши Spectrum

`PC controller` выбирает физическое устройство. `Game profile` выбирает
управление для игры; `Emulates` выбирает интерфейс эмулируемой машины.
Именованный профиль сохраняет весь набор: интерфейс, движение, мёртвую зону,
Fire, дополнительные Fire, автоогонь и клавиши Spectrum. Физическое устройство
остаётся выбором машины: профиль можно применять с другим геймпадом.

1. Выбрать контроллер и нажать `New / Copy`, назвать профиль, например Elite.
   Текущие назначения копируются. Уникальные имена; Standard зарезервирован.
2. Нажать `Spectrum key assignments...`, затем `Add...`.
3. Выбрать клавишу Spectrum, при необходимости Caps Shift / Symbol Shift,
   нажать поле Controller и кнопку/ось/крестовину своего устройства.
4. Подписать действие (необязательно), нажать OK. В списке зелёным показываются
   активные назначения; двойной щелчок редактирует строку.
5. Нажать OK, затем **Apply** в Machine Settings.

Все 40 клавиш и сочетания замыкают контакты матрицы Spectrum и совмещаются
с обычной клавиатурой. События Windows не генерируются. Например, назначение
P — пауза самой игры, не глобальная Pause эмулятора. Дополнительные игровые
клавиши доступны в каждом интерфейсе, включая обычный Kempston.

По умолчанию одна кнопка имеет одно назначение. При конфликте можно заменить
старое либо отменить. Кнопки игровых действий исключаются из `Any button` и
дополнительных Fire; оси/POV, назначенные на клавишу, исключаются из
автоматических направлений. Удалённое назначение снова освобождает источник.
В Kempston Extended дополнительные Fire имеют отдельные назначения,
по умолчанию кнопки 2/3/4, и исключаются из `Any button`. Этот режим соответствует
8-битному расширению, уже имевшемуся в BaseConf; игра должна его поддерживать.
В других интерфейсах эти строки скрыты. Для обычных игр удобнее клавиши Spectrum.

Standard хранит отдельное управление каждого контроллера в конфигурации машины.
Именованные профили хранятся в `joystick-profiles.xml` рядом с ZXMAK2.exe,
при замене файла сохраняется `.bak`. В машине сохраняется имя и полная копия
активного профиля: отсутствие файла библиотеки не ломает запуск.
После перезапуска сохраняются выбранные контроллер и профиль. Возврат к Standard
восстанавливает прежние назначения этого контроллера, включая интерфейс.

`Import...` и `Export...` переносят профили между сборками. Импорт с совпадающим
именем создаёт копию с числовым суффиксом, не заменяя существующее управление.
Удаление и восстановление стандартных назначений требуют подтверждения.
Изменения библиотеки записываются только при окончательном Apply: Cancel,
перестроение страницы при Add и закрытие окна не записывают черновик.
Экспорт по явному нажатию пользователя сохраняет выбранный профиль отдельно.
Factory Reset возвращает выбор машины к её исходным настройкам; общая библиотека
пользовательских профилей остаётся для дальнейшего использования.

Отключённый контроллер сохраняется в списке; обучение и управление для него
серые. Refresh не меняет выбор на другое устройство. На D-pad only мёртвая
зона неактивна. Потеря фокуса, остановка/пауза, сброс и отключение отпускают
виртуальные клавиши и прекращают защёлкнутый автоогонь. Нажатие новых кнопок
после возврата обрабатывается обычным образом.

## Проверка и источники

Автопроверки `tools/BaseConfConfigTest/JoystickProbe.cs`: POV/диагонали,
мёртвая зона, противоположные направления, нормализация DInput/XInput,
назначения, 8-битный порт, XML, отсутствующее устройство, UI Refresh,
автоогонь/сброс/фокус и часы реальной модели BaseConf.
Также проверяются все комбинации контактов пяти интерфейсов, выбор
неактивных/нескольких строк матрицы и одновременные обычные клавиши.
Требуется пользовательская проверка физического геймпада и HOTAS:
при сборке подключённых PC-контроллеров не обнаружено.
